CLOSED LOOP

质量闭环的七个证据点

  1. 标准

    规格、方法、抽样和版本明确。

  2. 样本

    可定位到批次、SN、工序或出货批。

  3. 结果

    原始值、单位、量具、时间和判定完整。

  4. 范围

    不合格影响对象形成可审计快照。

  5. 处置

    决定、批准、任务和数量一致。

  6. 复验

    引用原 NCR 与处置证据，不覆盖原失败。

  7. 效果

    趋势和 CAPA 验证风险是否真正下降。

STATE VECTOR

制造、质量、库存三类状态分离

制造状态

待开工、加工中、已完工，回答产品做到了哪一步。

质量状态

待检、合格、冻结、特采、报废，回答能否继续流转。

库存状态

待接收、可用、已分配、隔离、出库，回答实物在哪里及如何使用。

JAVA IMPLEMENTATION

实现切面

  • 规则版本历史实测值永远引用当时规格，标准更新不重算旧结论。
  • 冻结传播以对象 + 版本幂等同步 MES/WMS，并通过对账发现漏执行。
  • 权限分离检验、改判、特采和放行分别授权，关键决定电子签名。
  • 范围快照审批时固定影响清单或数据水位，避免处置期间范围漂移。

VERIFY

验证清单

  • 规格更新后历史检验是否仍可复现
  • 冻结批次是否命中已绑定整锁和库存箱码
  • 再次复验失败是否回到重新评审
  • 制造完工是否会误触发库存可售
  • 特采是否记录范围、条件和批准人
  • 处置数量与冻结范围数量是否守恒
