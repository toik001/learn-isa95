SYSTEM 03 · MES

MES：现场执行事实中心

MES 连接计划与现场，主责工单执行、WIP、SN、过站、投料、绑定和业务采集证据；它记录事实，但不替代经营、设计、质量和仓储主权。

主权：执行 / WIP / SN / 绑定上接：ERP / PLM / QMS下接：工位 / 设备 / WMS

DATA OWNERSHIP

MES 的权威现场事实

工单执行

接收/拒绝、派工、开工、暂停、完工、报废和现场进度。

单件在制

整锁 SN、当前工序、每次过站、返工和实际人员/设备/时间。

用料与谱系

工序投料、物料批次、关键件 SN、绑定/解绑和实际消耗。

采集摘要

固件、设备程序、测试会话、业务结果和原始数据索引。

CAPABILITIES

MES 要守住的现场控制

  1. 制造快照

    只执行工单冻结的受控版本。

  2. 开工门禁

    人、机、料、法、质量条件缺一不可。

  3. 单件路线

    前序、工序尝试、返工和跳站受控。

  4. 身份绑定

    SN、关键件、固件、测试会话保持唯一可追。

  5. 实绩反馈

    向 ERP/WMS/QMS 回传事实而非推测状态。

BOUNDARIES

MES 不应越界做什么

不可替代原因正确交互
ERP 经营与财务订单、成本、财务库存有独立治理MES 回传实际领料/完工/报废。
PLM 设计审批现场不能自行改产品定义引用发布版本，反馈变更需求。
WMS 仓内移动库位与容器实物由仓储控制发起请求并接收移动结果。
QMS 质量放行制造完成和质量允许是独立决定执行冻结/返工，引用放行结论。
设备原始控制高频闭环和安全互锁属于 OT传业务上下文，接收会话结果。

RISKS

常见设计错误

  • 只记录工单总产量，没有逐 SN 工序与版本证据。
  • 用一个状态混合制造、质量、包装和库存。
  • 设备 PASS 直接过站，未校验身份、路线和程序。
  • 为“方便”提供改历史、删失败和通用补录权限。

BOUNDARY CHECK

边界验收

  • 每个外部字段是否标明来源和版本
  • 单件过站是否有唯一业务键
  • 工单状态与外部状态是否显式映射
  • 部分成功是否有补偿与对账
  • 异常是否保留原始失败和处置
  • 任一已交付 SN 是否可还原制造全过程
