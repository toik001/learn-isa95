LAYER 01 · BUSINESS

业务层：一件产品一条不可抹除的制造履历

触发是已下达工单满足开工条件，或上游工序完成带来的节拍拉动。完成不是“工单报了数量”，而是每个整锁 SN 完成冻结路线、关键件与固件绑定、测试证据和异常闭环。

关键岗位

生产主管、班组长、操作员、物料员、工艺/设备工程师、质量人员和 MES 管理员。

进入条件

人员资质、设备校准、工装、制造基线、齐套物料、作业指导和 SN 规则均有效。

退出条件

必经工序完成，消耗与绑定完整，固件可核验，测试合格或已有批准处置，数量对账成立。

  1. 派工与开工校验

    选择工单/工序和班次，校验操作者资质、设备/工装状态、物料齐套和最新停线通知。

  2. 生成或接收整锁 SN

    SN 与工单、产品、制造版本建立关系；重打标签不得生成第二个有效身份。

  3. 工序进入与过站

    检查前序成功、返工路线和当前 WIP 状态，记录进入、开始、完成、失败、暂停和每次尝试。

  4. 投料与关键件绑定

    扫描主板、指纹模组、电机等关键件，校验版本、质量和唯一性后建立装配关系。

  5. 固件烧录与设备采集

    由系统选择受控固件和设备程序，记录下载/烧录/回读哈希、测试会话、原始数据索引和业务判定。

  6. 异常、返工和换件

    失败先暂停或隔离，再通过批准路线返工；解绑/换件追加有效期记录，原失败与旧件历史不删除。

  7. 末工序完工申报

    核对路线、绑定、固件、质量、用料、报废和工单数量，生成完工事实但不越权替代质量放行。

智能锁案例：LOCK-260728-000123 绑定 PCB-SN-88421、FP-SN-39210 和锁体批次，烧录固件 2.3.4 并保存 SHA-256。电机电流超限后产品暂停；换件、走返工路线并复验合格，系统保留原电机、失败测试和处置批准。

LAYER 02 · DATA

数据层：过站记录要表达“每次尝试”，不能只存最终 PASS

WIP / 整锁 SN

单件聚合

SN、工单、产品/版本、当前工序、执行状态、质量状态、包装状态、最新事件序号和创建来源。

过站记录

工序事实

SN、路线/工序版本、尝试号、进入/完成时间、人员、工位、设备、结果、失败码和返工来源。

装配绑定

制造谱系

父 SN、子件 SN/物料批次、数量、工序、绑定/解绑时间、原因、操作者和有效状态。

烧录 / 测试会话

设备证据

会话 ID、SN、设备、程序/固件版本、哈希、开始结束、原始数据地址、规则版本、结果和重发序号。

单件执行参考状态

  1. 已创建
  2. 待开工
  3. 加工中
  4. 工序完成
  5. 待下工序
  6. 已完工

失败可进入暂停、待处置、返工中、待复验或报废。“制造已完工”与“质量已放行”必须是正交状态，避免一个状态字段承载所有语义。

业务不变量校验失败处理
前序门禁当前路线要求的前序均有有效成功记录拒绝过站；跳站仅走授权命令并审计。
关键件唯一子件 SN 同时只能绑定一个有效父 SN拦截并调查来源，不自动解绑旧关系。
数量守恒合格 + 报废 + 在制不超过投入，完工不超过授权进入对账队列，禁止静默改数。

LAYER 03 · SYSTEM

系统层：MES 保存业务事实，设备系统保存高频原始证据

系统主责边界
MES工单执行、WIP、过站、绑定、业务判定和实绩不接管 PLC 控制；保存原始数据索引和可复核摘要。
设备 / SCADA设备控制、程序日志、采样点、报警和原始文件设备 PASS 不自动等于 MES 过站，仍需身份、版本和路线校验。
PLM / QMS制造依据 / 质量处置提供受控版本和处置结论，MES 记录实际执行引用。
ERP / WMS经营汇总 / 实物配送接收完工消耗与补料需求，不逐步控制单件工序。

LAYER 04 · IMPLEMENTATION

实现层：单件状态条件更新 + 同事务事实写入

  • 过站原子性同一事务写过站、当前 WIP 状态、消耗/绑定和 Outbox；外部系统失败由事件补偿。
  • 条件更新更新时携带期望工序、状态和版本，受影响行数为 0 即并发冲突或重复请求。
  • 设备会话幂等以测试会话 ID + 结果序号防重和排序；迟到结果进入待确认，不倒退已关闭状态。
  • 有效期绑定绑定是追加事件或带 from/to 的关系；解绑关闭旧关系并关联换件原因。
  • 离线续传终端使用本地事件队列，保持原事件 ID、工位时间和序号；服务端返回逐事件结果。
  • 例外权限跳站、补录、重打、解绑、改判和手工完工分别授权，强制理由、双人复核和审计。

CONTROL

异常闭环与指标

  • 设备 PASS 但 MES 超时：SN 保持结果待确认 → 设备按会话 ID 重发 → MES 幂等落库 → 核对唯一结果 → 必要时授权补采。
  • 关键件重复绑定：拒绝第二次绑定 → 查询旧父件状态 → 判断扫码错、返工未解绑或数据重复 → 受控修复并审计。
  • 工位断网：只允许预授权工单/版本离线执行 → 本地保留签名事件 → 恢复后按序续传 → 冲突进入人工判定。
工序 FPY / 整路线 RTYFPY 看单工序一次通过；RTY 为各工序 FPY 乘积
单件周期 / 在制等待区分有效加工、搬运、排队和异常停留
绑定与采集完整率应采证据中已形成有效记录的比例
