LAYER 01 · BUSINESS

业务层：从制造完成到可管理库存的责任交接

触发是末工序完工且质量允许包装/入库。完成标志是产品、版本、数量、箱码、SN 清单、仓库和库位一致，WMS/ERP 接收成功，差异与待处理对象没有被隐藏。

关键岗位

包装操作员、班组长、成品检验、仓库收货/上架、生产计划、订单运营和财务。

进入条件

SN 路线完整、质量放行、包装规范/标签模板有效、箱码规则和目标仓库/库位可用。

退出条件

所有 SN 归属唯一有效箱码，入库单实收与装箱数量一致，库存状态可解释，系统间完成对账。

  1. 包装前门禁

    校验整锁 SN、产品配置、固件、质量状态、附件齐套和客户标签要求。

  2. 生成包装单元

    创建单盒、外箱、托盘码；扫描建立父子层级并校验容量、同批/混批和配置规则。

  3. 打印与复核标签

    标签绑定模板版本与打印任务；重打使旧标签失效并记录原因，防止两个有效码。

  4. 创建入库交接

    MES 按完工与装箱生成入库请求，仓库实扫箱码/托盘码接收，差异进入待处理区。

  5. 上架与库存确认

    WMS 指派库位并确认实物移动；ERP 记录库存与完工账，MES 更新仓储交接状态。

  6. 数量与状态对账

    逐 SN 核对未装箱、重复装箱、已冻结、已入库和待处理数量；工单结清不能掩盖差异。

智能锁案例：10 把锁装一箱，20 箱一码托盘。包装时发现一把锁的固件为出口版而订单配置为国内版，系统阻止装入同箱并将该 SN 转待处理；其余 9 把可临时保留在开放箱，但不能先生成“满箱入库”。

LAYER 02 · DATA

数据层：包装层级是一棵带有效期的树

包装单元

箱 / 托盘身份

包装码、类型、产品/配置、容量、状态、创建工位、模板版本、创建时间和失效原因。

包装成员

父子展开关系

父包装码、子包装码或整锁 SN、装入/移出时间、操作人、有效状态和原关系。

入库单 / 实收

交接凭证

来源工单、目标仓库、产品版本、计划/实收数量、箱码清单、质量状态、收货人和差异。

库存单元

仓储位置与可用性

箱码/托盘、库位、数量、质量状态、分配状态、所有权、入库时间和来源凭证。

三个正交状态维度

  1. 制造：已完工
  2. 质量：已放行/冻结
  3. 包装：开放/封箱
  4. 仓储：待接收/已入库/已上架

这些不是单线状态机。产品可制造已完工但质量冻结；箱可已封箱但尚未入库；已入库库存也可能已分配给原订单。已分配库存仍可履行对应订单，只有未分配余量可供新订单分配。

数量检查等式或约束异常示例
工单产出完工 = 待包装 + 已包装 + 待处理补打 SN 导致重复计数。
箱内成员有效成员数 ≤ 箱容量换箱时旧关系未关闭造成双重归属。
入库实收实收 = 已接收有效箱内 SN 数按箱头数量入库却未展开冻结成员。

LAYER 03 · SYSTEM

系统层：MES 证明装了什么，WMS 证明放在哪里

系统主责交互边界
MES制造完工、包装结构、SN/箱码关系和入库请求不自行确认仓库库位和财务库存。
WMS收货、库存单元、库位、上架和仓内移动接收可展开箱码，不修改制造谱系。
ERP完工、库存财务账和成本结转接收批准结果；失败通过重试或冲销，不覆盖 MES 实绩。
QMS成品冻结与放行冻结事件必须能命中箱内 SN 和库存单元。

LAYER 04 · IMPLEMENTATION

实现层：唯一归属、分步交接和可恢复打印

  • 包装唯一性数据库约束保证 SN 同时最多属于一个有效包装；换箱在事务内关闭旧关系并创建新关系。
  • 层级防环装托时校验父子类型、层级深度和循环引用；展开查询限制深度并检测坏数据。
  • 标签打印打印任务有模板版本、次数和结果；重打先作废旧标签，设备异常可安全重试。
  • 交接 SagaMES 请求、WMS 收货/上架、ERP 记账各有独立状态和幂等键；失败保留可见的待处理状态。
  • 数量对账定时比较 MES 装箱、WMS 实收与 ERP 凭证，按工单/入库单/箱码输出差异。
  • 冻结传播SN 冻结需计算并标记受影响箱/库存单元，但不能无审计地拆箱或删除成员。

CONTROL

异常闭环与指标

  • 箱码重复：停止使用两个标签 → 读取打印与装箱记录 → 确认唯一有效箱 → 作废错误码并重新贴标 → 盘点成员。
  • WMS 少收一箱：保持入库“部分接收” → 定位实物、扫描和接口日志 → 补收或撤销交接 → 三方数量对账。
  • 入库后质量冻结：锁定库存分配/出库 → 展开箱内 SN → 转移隔离库位 → 处置后按原冻结范围放行。
入库及时率质量放行后在目标时限内完成实收入库
装箱准确率产品、配置、数量和成员一次正确比例
账实一致率MES、WMS、ERP 与现场盘点一致程度
