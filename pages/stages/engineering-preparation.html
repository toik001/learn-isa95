LAYER 01 · BUSINESS

业务层：设计定义必须经过制造化

触发包括新产品导入、配置扩展、物料替代、工艺优化、质量整改、固件升级和工程变更。完成标志是 MBOM、工艺路线、作业指导、检验方案、设备程序和固件适用范围一起发布，并能被工单冻结。

关键岗位

产品研发、结构/电子/嵌入式工程师、工艺、质量、设备、生产、采购、主数据和信息化。

进入条件

产品型号、EBOM、图纸和设计版本已受控；工作中心、物料编码、设备能力、人员技能和检验资源可用。

退出条件

制造基线已审批发布，试制问题关闭，生效条件明确，旧版本仍可按历史工单复现。

  1. 建立 EBOM 与设计基线

    明确锁体、面板、主板、指纹模组、电机、电池组件、结构件和包装材料的设计组成及替代限制。

  2. 转换并补充 MBOM

    按装配顺序拆分投料点，补充工艺辅料、包装件、损耗、替代组和 EBOM 行来源。

  3. 定义工艺路线

    为装配、烧录、绑定、功能测试、外观检查、包装等工序定义前后关系、门禁、资源和返工路线。

  4. 发布质量与设备配方

    把检验特性、规格上下限、抽样/全检策略、设备程序和参数范围关联到产品及工序版本。

  5. 管理固件与适用范围

    保存版本、文件哈希、签名、硬件兼容、区域/客户限制、烧录程序和回读校验策略。

  6. 试制验证并正式发布

    验证可装配性、节拍、良率、防错和追溯完整性，关闭问题后定义日期、批次或工单生效条件。

智能锁案例：主板从 V2 升为 V3 后，固件需升级至 2.3.x，测试台程序也需切换。若只改 BOM 而未同步固件适用范围和测试规格，现场可能“能装上但无法通信”，这就是制造基线不完整。

LAYER 02 · DATA

数据层：版本不是备注，是追溯主键的一部分

产品 / EBOM

设计定义

产品型号、设计版本、EBOM 头/行、父子物料、数量、位号、替代约束、来源变更和发布状态。

MBOM

制造用料

制造版本、工序投料点、用量、损耗、替代组、追溯粒度、EBOM 行来源和生效范围。

工艺路线

执行顺序

路线版本、工序、前后约束、工作中心、资格、设备/工装、标准工时、过站条件和返工路径。

检验 / 固件

判定与软件基线

规格版本、特性、上下限、方法、抽样规则；固件版本、哈希、签名、硬件范围、客户范围和失效原因。

参考状态流

  1. 草稿
  2. 评审中
  3. 试制
  4. 待批准
  5. 已发布
  6. 受限使用
  7. 已失效

“已失效”不能物理删除；历史工单仍应解析到当时冻结的 MBOM、路线、检验与固件版本。

快照对象工单必须冻结什么为何不能只存最新版
产品 / MBOM头版本、行版本或不可变发布 ID解释实际用料与替代是否合法。
路线 / 检验路线版本、工序、规格版本解释为何允许过站、当时按什么标准判定。
固件发布 ID、版本、哈希、硬件范围文件名相同不等于二进制内容相同。

LAYER 03 · SYSTEM

系统层：PLM 管设计发布，MES 管现场使用证据

系统主责数据边界与交互
PLM产品、图纸、EBOM、设计版本、工程变更发布受控定义，不记录现场实际使用。
ERP物料主数据、制造 BOM、计划参数和成本口径承接经营与计划所需制造定义；具体主责边界待企业确认。
MES工单快照、路线执行规则、工位版本接收发布版本，冻结到工单并记录每个 SN 的实际版本。
QMS检验标准、抽样、质量变更向 MES 提供规格版本，接收实际检验结果。
设备系统设备程序、配方、原始参数与 MES 发布 ID 对齐，回传实际程序/参数摘要。

LAYER 04 · IMPLEMENTATION

实现层：不可变发布物 + 有效期关系

  • 不可变版本已发布版本禁止原地修改；修订产生新版本，工单引用稳定的发布 ID。
  • 行级来源MBOM 行保存 EBOM 行来源与转换类型，支持设计变更影响分析和成本解释。
  • 有效范围用产品、工厂、日期、批次、工单或客户范围表达生效；检测重叠与空档。
  • 发布一致性本地事务写发布状态和 Outbox；各系统消费后回传版本校验结果，失败可重放。
  • 固件安全对象存储文件与元数据分离；下载、烧录前校验哈希与签名，记录实际摘要。
  • 差异视图前端逐项展示 BOM、路线、规格和固件的新增、删除、替换及影响工单。

CONTROL

异常闭环与指标

  • 版本发布不完整：发现路线已发布但检验规格未发布 → 阻断计划下达 → 补齐审批 → 做跨系统版本一致性检查。
  • 工程变更撞上在制：按未下达、已备料、已开工、已完工分类 → 决定旧版继续、返工、报废或升级 → 保存逐对象结论。
  • 固件与硬件不兼容：烧录前由产品、主板版本、客户区域和固件范围联合校验；不允许操作员凭文件名选择。
发布一次通过率制造基线首次评审即可发布的比例
变更影响准确率实际受影响对象与分析清单的一致程度
错版拦截率上线前被系统阻止的 BOM/路线/固件错版次数
