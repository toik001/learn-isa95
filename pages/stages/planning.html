LAYER 01 · BUSINESS

业务层：从供需平衡到现场可执行承诺

触发来自销售订单、预测补库、安全库存、返工补产或售后备件。完成标志是工单冻结产品、MBOM、路线、检验和固件版本，并通过物料、产能、设备和人员等开工前校验后下达 MES。

关键岗位

主计划员、物料计划员、车间调度、生产主管、采购、仓储、工艺、质量和设备工程师。

进入条件

需求基线、库存/在制/在途快照、MBOM、路线、提前期、工作中心和设备日历有效。

退出条件

工单有来源、有版本、有数量、有资源、有计划时间，约束冲突已处理，现场明确接单。

  1. MPS 汇总独立需求

    合并订单、预测和安全库存，扣减成品库存、已确认在制和不再有效的预测重复量。

  2. MRP 展开相关需求

    按 MBOM 计算净需求，考虑库存状态、在途、损耗、替代、采购/生产提前期和最小批量。

  3. 建立并拆分生产工单

    按产品配置、交付批次、追溯粒度、换线经济性和产线能力拆单，保存订单分配。

  4. 有限产能排程

    校验班次、人员、设备、工装、维护、质量等待、物料可用日和换线矩阵，识别瓶颈。

  5. 冻结近期计划并下达

    冻结窗口内变更提高审批等级；下达时生成制造快照并由 MES 返回接受或拒绝原因。

  6. 滚动重排

    对缺料、停机、质量冻结和插单建立新排程版本，保留旧方案、约束差异和人工原因。

智能锁案例：3,000 套订单包含 2,000 套深灰与 1,000 套银色。APS 为减少颜色换线先连续排深灰，但指纹模组仅可支撑 1,200 套，于是拆成两个深灰工单并将剩余量排到到料日之后；每个工单都保存订单行分配数量。

LAYER 02 · DATA

数据层：计划、工单和排程版本回答不同问题

MPS / MRP 建议

应该供给什么

需求来源、物料、需求日期、净需求、建议数量、建议日期、供给类型、计算批次和例外消息。

生产工单

授权制造什么

工单号、产品与制造版本、计划数量、来源需求、工厂/产线、优先级、计划起止、状态和变更版本。

工序计划

资源何时执行

工单/工序、资源、计划时间、标准工时、准备/加工时长、前后约束、锁定标记和派工数量。

排程版本

为什么这样排

版本、算法/规则、输入快照、瓶颈、人工调整、原因、发布时间和被替代版本。

工单参考状态机

  1. 计划建议
  2. 已创建
  3. 已排程
  4. 已冻结
  5. 已下达
  6. 执行中
  7. 已完工
  8. 已关闭

暂停、终止、取消和变更评审是受控分支。“已下达”表示授权现场准备，“执行中”必须由实际开工事实触发。

对象数量语义对账要求
工单计划数量被授权生产的数量等于订单分配、补库与其他来源分配合计。
派工数量某班次/工序当前被安排的数量不应超过工单剩余可派数量。
完工 / 报废数量现场实际结果与 WIP、物料消耗及 ERP 汇总一致。

LAYER 03 · SYSTEM

系统层：计划建议与执行事实必须分开

系统主责本阶段边界
ERPMPS/MRP、生产订单与经营数量决定供给需求及财务口径，接收 MES 实绩。
APS有限产能排程建议计算约束方案，不直接伪造开工或完工事实。
MES工单接收、派工和执行状态校验制造快照，拒绝不完整或失效版本，并回传实际进度。
WMS / QMS / 设备物料可用日、质量冻结、设备可用性作为排程约束来源，需带快照时间和可信状态。

LAYER 04 · IMPLEMENTATION

实现层：命令、乐观锁与可取消长任务

  • 命令模型下达、拆分、合并、暂停和取消使用显式命令，逐项校验状态、数量与影响。
  • 并发控制工单和资源时段用乐观锁或条件更新，防止调度员相互覆盖与重复下达。
  • 异步排程排程作为有任务 ID、进度、输入快照和取消信号的异步作业；结果发布需二次校验。
  • 时间语义统一工厂时区、班次跨日、维护窗口和假日日历；数据库存储明确时区语义。
  • 幂等同步工单事件按来源 ID + 版本防重；旧版本事件进入冲突队列，不覆盖新状态。
  • 可解释排程记录约束、目标权重、瓶颈和人工拖拽原因，允许比较两个版本的交期影响。

CONTROL

异常闭环与指标

  • 关键模组晚到：定位受影响工单/订单 → 比较替代、换序、拆单、调拨或延期 → 发布新排程 → 同步备料和承诺风险。
  • 设备突发停机：冻结对应资源时段 → 评估转线资质与工装 → 迁移未开工任务 → 对已开工 WIP 建立处置单。
  • 紧急插单：先量化对冻结区和既有客户的影响 → 获得业务批准 → 生成新版本，而不是直接改工序时间。
计划达成率按冻结计划完成的工单/数量比例
排程稳定性冻结窗口内未被重排的任务比例
瓶颈负荷率瓶颈资源有效加工时间 / 可用时间
