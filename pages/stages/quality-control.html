LAYER 01 · BUSINESS

业务层：质量不是末端检查，而是贯穿采购、过程与成品

检验可由采购到货、首件、工序完成、巡检计划、设备报警、末工序完工、客诉或供应商通知触发。完成标志是检验结论、风险对象、处置、复验和放行都有可验证证据。

关键岗位

IQC、IPQC、OQC、质量工程师、班组、工艺/研发、仓储、计划、供应商质量和授权批准人。

进入条件

检验对象明确，规格与抽样版本有效，量具/设备校准合格，样本可定位到批次或 SN。

退出条件

合格对象放行；不合格对象已隔离并按批准决定返工、返修、报废、退货或特采，复验和数量闭环。

  1. 按事件生成检验任务

    关联来料批次、工单/工序、整锁 SN、包装批或出货批，并冻结使用的检验方案版本。

  2. 抽样或逐件采集

    记录样本身份、特性、实测值、单位、设备/量具、人员、时间和原始数据索引。

  3. 规则判定与人工确认

    按当时规格版本计算单项与总体结论；人工改判必须具备权限和理由。

  4. 不合格隔离

    创建 NCR，冻结批次、SN、容器和关联在制，物理隔离与系统状态同步。

  5. 评审并执行处置

    MRB 评估影响，批准返工、返修、报废、退货或特采；处置任务逐对象执行。

  6. 复验与独立放行

    引用原 NCR 和处置记录生成复验；合格后由授权人放行，重复失败回到重新评审或关闭。

  7. 趋势与 CAPA

    对重复缺陷分析产品、版本、设备、班次、供应商和物料批次，验证纠正预防措施效果。

智能锁案例：功能测试发现同一批主板装配的 8 把锁通信间歇失败。QMS 冻结主板批次和已绑定 SN；评审确认需升级固件并复验。系统保留原失败结果、升级记录、复验结果和逐 SN 放行，不能批量把原结果改成 PASS。

LAYER 02 · DATA

数据层：检验、处置和放行是三个独立事实

检验任务 / 样本

谁按什么检查

任务来源、对象类型/ID、检验方案版本、抽样方案、样本 SN、检验员、计划/实际时间和状态。

特性结果

测到了什么

特性、实测值、单位、规格上下限、判定、设备/量具、原始数据地址、时间和改判信息。

NCR / 处置

风险怎么处理

缺陷、严重度、影响范围快照、隔离位置、原因、决定、批准人、处置任务、数量和完成证据。

复验 / 放行

为什么可以流转

原 NCR、处置记录、复验任务、结论、放行对象、放行人、时间、适用范围和例外条件。

质量事件参考状态

  1. 待检
  2. 检验中
  3. 待判定
  4. 已判定
  5. 待处置
  6. 已定处置
  7. 待复验
  8. 已关闭

再次不合格 → 待重新评审 → 已定处置 / 已关闭；重复复验不能无限循环且不能跳过新处置决定。

正交维度示例状态不可混淆
制造状态加工中 / 已完工已完工不代表质量合格。
质量状态待检 / 合格 / 冻结 / 特采合格不代表已经入库或可销售。
处置状态待评审 / 返工中 / 已报废处置完成后仍可能需要复验。

LAYER 03 · SYSTEM

系统层：QMS 管质量闭环，MES 执行现场门禁

系统主责交互
QMS标准、抽样、NCR、MRB、CAPA 与放行下发检验/冻结/处置，接收实际结果和执行证据。
MES过程检验执行、SN/WIP 门禁和返工路线阻止冻结对象过站或完工，记录处置实际执行。
WMS库存质量状态与物理隔离位置根据有效冻结/放行指令限制分配和移动。
设备系统原始测试与测量数据提供会话与原始值，业务判定引用规格版本。
ERP采购退货、报废和财务后果接收批准的质量处置结果，不自行改判。

LAYER 04 · IMPLEMENTATION

实现层：规则版本、范围冻结与长事务工作流

  • 判定可复现保存原始值、单位、规格版本和规则结果；后续标准变化不能重算覆盖历史。
  • 范围快照冻结/召回在批准时保存对象清单或可校验查询版本，避免执行过程中范围漂移。
  • 跨系统门禁冻结事件携带对象、版本和有效期；MES/WMS 幂等消费，并通过对账识别漏冻结。
  • 工作流并发MRB 决定用版本号防并发覆盖；处置批准后不可修改，只能撤销并产生新决定。
  • 权限分离检验、改判、特采批准和最终放行分权；关键操作支持双人复核和电子签名。
  • 证据附件图片、曲线和报告存对象存储，数据库保存哈希、来源、权限和生命周期。

CONTROL

异常闭环与指标

  • 结果已上传但量具过期：冻结受影响任务 → 确认校准失效起点 → 圈定样本/批次 → 重新测量或风险评估 → 修复设备门禁。
  • QMS 冻结成功、WMS 未执行：重复投递并告警 → 暂停相关分配 → 对账已移动库存 → 补冻结和物理隔离。
  • 复验再次失败：回到重新评审，重新定义处置或终止为报废/退货；禁止只增加复验次数直至偶然合格。
