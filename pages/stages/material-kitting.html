LAYER 01 · BUSINESS

业务层：库存存在、已分配、已到线、已投料是四种事实

触发通常是工单下达、近期计划冻结、看板拉动或线边最低库存。完成标志不是拣货单关闭，而是工单需求与线边实物扫描核对，质量状态、批次、替代和数量均允许投料。

关键岗位

物料计划员、拣货/复核/配送员、线边物料员、班组、质量、采购、工艺和计划员。

进入条件

工单及 MBOM 有效；仓库/库位、容器、批次、质量状态、替代组、有效期和投料点已定义。

退出条件

可投料量覆盖开工批量，关键批次或 SN 已核对，缺料方案明确，账卡物与分配关系一致。

  1. 计算工单净需求

    按 MBOM 扣减已领、已投、可复用余料和线边可用量，区分开工齐套与完工齐套。

  2. 按策略分配库存

    WMS 应用 FIFO/FEFO、同批优先、质量状态、客户限制和保留策略，不得分配待检或冻结库存。

  3. 拣货、复核与配送

    扫描物料、批次/关键件 SN、容器、库位和数量；复核错料、混批及容器关系。

  4. 线边接收和齐套判定

    接收人确认实物到位；部分齐套可支持分批开工，但必须暴露剩余缺口与预计到料。

  5. 投料前防错

    MES 校验产品/MBOM 版本、工序投料点、替代批准、有效期、质量和重复绑定。

  6. 领退补料对账

    完工前处理超领、余料、退料、报废和换件；退料引用原领料与原批次，不能产生断链。

智能锁案例：500 套工单中，主板按批次、指纹模组按 SN、螺钉按数量追溯。第二批主板仍待检，只允许已放行的 300 件进入可投料区；系统把工单标为“部分齐套”，允许先开工 300 套但持续显示剩余缺口。

LAYER 02 · DATA

数据层：需求与库存批次通过分配和领料形成多对多

工单物料需求

应消耗什么

工单、MBOM 行、物料、需求/已领/已投/退回数量、投料工序、替代组和追溯粒度。

库存批次 / 库存单元

哪里有什么

物料、批次、供应商批次、容器、库位、数量、质量状态、有效期、所有权和分配状态。

分配 / 拣配 / 领料

预留与移动证据

需求行、库存单元、分配数量、策略、拣货任务、操作人、扫描时间、目标线边和凭证状态。

投料 / 绑定

实际使用证据

整锁 SN/工单、工序、物料批次或关键件 SN、数量、设备/人员、时间、结果、替代批准和原记录。

齐套状态与缺料处置

  1. 待计算
  2. 待分配
  3. 部分分配
  4. 拣货中
  5. 已到线边
  6. 部分齐套
  7. 已齐套

部分齐套 → 缺料处理中 / 已齐套；未解决缺料可进入待重新评审 → 缺料处理中 / 已取消 / 已关闭未解决，避免状态机只进不出。

追溯粒度智能锁示例记录方式
数量级螺钉、胶、包装辅料物料 + 批次 + 数量，按工单/工序消耗。
批次级锁体、电池组件、塑胶件供应商/企业批次到工单或整锁 SN 的用量关系。
序列号级主板、指纹模组、高价值电机关键件 SN 与整锁 SN 一对一或带有效期的绑定。

LAYER 03 · SYSTEM

系统层：WMS 管仓内实物，MES 管线边消耗

系统主责边界与同步
WMS库位、容器、库存单元、分配、拣配与仓内移动确认实物从仓库到线边；不替代工序投料判定。
ERP库存财务账、领退料凭证和采购供给接收汇总或逐笔凭证；失败用冲销/重试对账。
MES工单需求、线边接收、投料、消耗与绑定把批次/关键件 SN 连接到工序和整锁 SN。
QMS / PLM冻结放行 / 替代依据决定物料能否使用和替代是否适用，不由仓库口头决定。

LAYER 04 · IMPLEMENTATION

实现层：库存预留并发、扫码幂等和跨系统补偿

  • 预留并发用条件更新或预留明细保证可用量不为负；可用 = 在手 − 有效预留 − 冻结，不靠前端判断。
  • 扫码幂等终端生成事件 ID；服务端保存结果与业务键，弱网重复上传返回首次结果。
  • 规则版本批次策略、替代组和追溯粒度版本化；拦截消息显示违反哪条规则及当前版本。
  • Saga 补偿WMS 移库、MES 接收、ERP 记账无法做分布式事务；每步有状态、重试、冲销与人工接管。
  • 数量精度明确单位换算、批次拆分和小数精度；序列号物料必须整数且唯一。
  • 高风险权限超领、替代、解冻、负库存和手工绑定需分权、理由、附件与审计。

CONTROL

异常闭环与指标

  • 批次错料：扫描拦截 → 物理隔离 → 冻结可能已装配 SN → 复核容器/库存 → 重新拣配 → 账务冲销 → 验证防错。
  • 已分配后被冻结：撤销有效预留 → 找到关联工单 → 重新分配或触发缺料 → 已到线边实物必须召回隔离。
  • 退料无法识别原批次：禁止直接入可用库存；进入待判定区，补充证据或降级/报废，避免污染追溯。
开工前齐套率满足定义齐套条件的近期工单比例
拣配准确率物料、批次、数量和目标工单一次正确比例
缺料停线时长因物料不可用造成的有效生产损失时间
