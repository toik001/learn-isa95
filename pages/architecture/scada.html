SCADA：集中监视与监督现场

SCADA 汇集状态、报警和趋势，让操作者在授权范围内监督控制；实时联锁仍由控制器和安全系统负责。

OFFICIAL EXPLANATION

SCADA 在 OT 中做什么

NIST SP 800-82 Rev.3把 SCADA 纳入工业控制系统范畴，典型能力是集中采集远端状态、展示、报警、趋势和监督控制。

白话：SCADA 是现场集中驾驶台，不是生产订单和 SN 谱系系统。

DATA MODELS

点位与报警必须有语义

点位

资产、数据类型、单位、量程、质量码、时间戳和采集策略。

报警

条件、等级、延迟、抑制、确认、恢复、责任区域和首次故障。

SUPERVISORY COMMAND

“点了按钮”不是动作完成

  • 已请求
  • 已接收
  • 控制器已确认
  • 动作中
  • 完成/拒绝/失败

启停和模式切换仍需当前状态、权限、设备条件和控制器反馈。

SMART LOCK CASE

总装线堵料报警

SCADA 显示工位状态、堵料、故障和节拍趋势。班组长可确认报警并请求停线；急停与防护门由安全回路执行。停机事件上送 MES 后关联当时工单和在制 SN。

IMPLEMENTATION

Java 实现重点

  • 质量码数值 0 与通信失败必须区分。
  • 时间语义携带源时间、接收时间与时钟质量。
  • 命令阶段接受、确认、完成不可压成一个 200 OK。
  • 避免轮询表不用数据库轮询模拟工业实时采集。
