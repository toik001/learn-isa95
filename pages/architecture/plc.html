OFFICIAL STANDARD

IEC 61131-3 规范什么

IEC 61131-3规定可编程控制器的 ST、LD、FBD 等语言及 SFC 相关元素。

白话：PLC 擅长稳定、重复、可诊断地完成机器动作；Java 擅长业务规则、事务与跨系统协同。

PROGRAM STRUCTURE

一个可维护的设备程序

  • 输入映像与信号质量
  • 停止、准备、自动、手动、故障、维护模式
  • 步骤顺控和超时
  • 设备与过程互锁
  • 报警和首次故障
  • 配方与程序版本
  • 命令/状态握手块
  • 诊断与维护数据

MES HANDSHAKE

一次命令的可靠时序

  1. 写命令

    命令 ID、SN、工序、配方和版本。

  2. PLC 校验

    模式、空闲、本地配方和现场条件。

  3. 明确接受

    ACCEPTED 或具体拒绝码。

  4. 自主执行

    上位断线不破坏安全和确定性。

  5. 冻结结果

    保留到上位确认接收。

SMART LOCK CASE

整锁功能测试

PLC 控制夹具、电源、开关量和电机动作。MES 发送 SN 与测试方案 ID；PLC 执行并保留同一会话结果。通信超时后双方查询原命令，不创建第二次物理动作。

JAVA BOUNDARY

Java 不该越过的线

  • 不做急停、门锁、伺服闭环和毫秒级顺控。
  • 命令块不用零散寄存器写入模拟事务。
  • 地址隔离寄存器映射集中版本化，不散落业务代码。
  • 未知态HTTP 超时不等于 PLC 未执行。
