传感器、执行器与驱动：连接物理世界

传感器把物理状态变成可信信号，执行器把命令变成动作，驱动器把速度、位置或扭矩目标变成电机控制。

ISA-95 LEVEL 1

感知和操纵过程

ISA 官方的 L1 活动是感知和操纵生产过程；NIST 则将传感器、执行器和控制设备视为 OT 与物理环境交互的基础。

白话：上层所有数据最终都要落到“实际测到了什么、真的动了吗”，否则只是软件自说自话。

SIGNAL MODEL

一个数值不够

身份与量纲

资产、通道、类型、单位、量程、精度和刷新率。

质量与诊断

Good/Uncertain/Bad、断线、超量程和校准过期。

原始整数要经过明确缩放转成工程单位，禁止上层猜测 `32767` 是温度、位置还是故障值。

ACTION MODEL

输出与反馈必须闭环

执行器要定义失电/失气默认状态、动作超时和到位反馈。“夹紧命令为 1”不代表夹具已经夹紧；反馈不到位时控制器应停止顺序并报警。

SMART LOCK CASE

锁付工位的物理链

光电确认锁体到位，气缸夹紧，扭矩枪驱动执行锁付并返回扭矩/角度，位置反馈确认完成。任何传感器或工具质量异常都要与真实产品异常区分。

JAVA BOUNDARY

Java 应消费标准语义

  • 不做快速闭环滤波、联锁和动作超时留在控制层。
  • 单位入契约类型、精度、量程和质量码不可省略。
  • 故障分类过程、传感器和通信故障分别编码。
  • 新鲜度最后值必须显示采集时间，不能冒充实时。
