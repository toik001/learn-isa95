AUTHORITATIVE EXPLANATION

权威解释与白话

SAP将 WMS 描述为管理物料从进入仓库到移出的仓储运营系统。

白话：ERP 说账上有多少，WMS 要能告诉你哪一箱、哪个批次、在哪个库位、由谁搬去了哪里。

OBJECTS & STATES

实物和任务分开建模

实物对象

仓库、库区、库位、容器/LPN、物料、批次、序列号和质量状态。

任务状态

创建→分配→执行→确认；异常和取消必须保留原因。

可用、待检、冻结、已分配、线边、在途是库存属性或状态，不等于仓库任务状态。

MES HANDOFF

三种事实不能混

事实含义主要责任
移动实物改变位置WMS
分配库存承诺给任务WMS/ERP
消耗物料实际用于产品MES

SMART LOCK CASE

从 LPN 到整锁 SN

WMS 将主板批次 B240701 和指纹模组容器 LPN88 配送到 1 线；MES 扫描确认后，在实际装配时绑定每个主板 SN、模组 SN 与整锁 SN。余料退库后 WMS 重新接管位置。

IMPLEMENTATION

Java 实现重点

  • 交接事务号请求、实发、接收和退回可串联。
  • 部分履行支持短发、补发、替代料和分批确认。
  • 数量对账发料、投料、消耗、退料总量闭合。
  • 质量锁冻结批次不能因接口延迟被误投。
