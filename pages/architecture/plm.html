AUTHORITATIVE EXPLANATION

MBOM 的权威解释与白话

Siemens说明 MBOM 定义制造产品所需零件和装配件，并按制造意图组织产品定义。

白话：EBOM 说明产品设计由什么构成；MBOM 和工艺说明现场按什么结构、顺序和替代规则把它造出来。

RELEASE PACKAGE

MES 接收的不是“最新版”三个字

发布包至少包含发布 ID、型号、MBOM/工艺/固件版本、适用范围、有效期、内容哈希和替代规则。工单在发布时冻结快照，后续新版本不能改变已发生事实。

SMART LOCK CASE

主板 V2 切 V3

A100 主板从 V2 切到 V3，固件从 1.6.2 升到 1.7.0。MES 按工单生效条件锁定硬件、MBOM、工艺和固件兼容组合；烧录站不能自行选择所谓“最新固件”。

IMPLEMENTATION

Java 实现重点

  • 兼容矩阵硬件、固件、工艺、测试计划联合校验。
  • 不可变快照发布内容以哈希防止同版本号被替换。
  • 多维生效日期、批次、SN 范围和特批工单共同决定适用性。
  • 变更影响识别未开始、在制、已完工和已发货对象。
