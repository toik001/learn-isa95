FUNCTION TEST SEQUENCE

一次功能测试的九步闭环

  1. 定义冻结

    工单锁定型号、硬件、固件、工艺和测试计划。

  2. MES 门禁

    校验路线、物料、人员、设备、校准和冻结。

  3. 创建会话

    发送唯一 ID、SN、计划版本与哈希。

  4. 控制层接受

    校验模式、夹具和本地计划。

  5. 现场执行

    感知到位、夹紧、激励、采样并安全收尾。

  6. 原始取证

    保存步骤、程序、仪器、曲线和报警。

  7. 可靠上传

    网关按会话与序号补传。

  8. 业务判定

    MES 验证完整性、版本和幂等。

  9. 实绩反馈

    ERP 接收累计实绩，MES 保留逐件履历。

SN GENEALOGY

一把锁的最小证据图

销售订单 → 工单 → 制造发布包 → 物料批次/关键件 SN → 整锁 SN → 工序与设备会话 → 固件哈希 → 测试原始证据 → NCR/返工/放行 → 箱码/托盘 → 入库 → 发货 → 客户去向。

追溯查询只汇聚来源事实，不修改 ERP、PLM、WMS、QMS 或设备侧原始记录。
