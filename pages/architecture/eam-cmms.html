EAM / CMMS：管理资产能否继续生产

CMMS 集中维护信息和维护运营，EAM 扩展到资产全生命周期；MES 消费设备能力状态，而不是自己维护整套维修台账。

典型层级：L3/L4主权：资产 / 维护 / 校准来源等级：B

AUTHORITATIVE EXPLANATION

CMMS 与 EAM 的区别

IBM将 CMMS 概括为集中维护信息、支持维护运营的软件，并说明 EAM 覆盖更广的资产生命周期。

白话：CMMS 关注设备怎么保养维修；EAM 还关心资产从规划、采购、使用到退役。

CORE OBJECTS

资产不只是 equipment_id

资产树

资产、部件、位置、技术参数、寿命和关键等级。

维护资源

策略、工单、人员、备件、工具和校准证书。

CAPABILITY STATE

运行不等于可生产

  • 可用
  • 降级
  • 维护锁定
  • 故障
  • 校准过期
  • 验证待确认

设备即使在线且 RUNNING，也可能因校准、工装或程序不满足当前工艺而不可派工。

SMART LOCK CASE

扭矩枪达到保养阈值

EAM 创建保养工单并将设备能力置为维护锁定，MES 停止派工。维修后还需校准和首件验证，确认合格后 MES 才恢复生产授权。

IMPLEMENTATION

Java 实现重点

  • 能力快照派工时记录当时可用性、校准和程序条件。
  • 故障线索设备事件可触发建议，但正式维修在 EAM 闭环。
  • 多层状态连接、运行、健康、能力和安全状态不能合并。
  • 释放门禁维修完成不等于可生产，须验证确认。
