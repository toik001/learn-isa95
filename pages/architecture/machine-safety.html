机器安全：危险时进入定义的安全状态

机器安全不是普通报警，而是通过风险评估、安全功能、合适架构和验证，使人员面临的风险降到可接受水平。

覆盖：L0—L2主权：安全功能 / 安全状态来源等级：A

OFFICIAL STANDARD

IEC 62061 关注什么

IEC 62061:2021规定机械安全相关控制系统的设计、集成与验证方法。

白话：目标不是让页面显示“正常”，而是在门打开、急停或安全元件失效时，机器确实按设计停止危险并防止意外重启。

SAFETY LIFECYCLE

从危险识别到变更管理

  1. 界定机器

    用途、人员、模式和生命周期。

  2. 评估风险

    危险、暴露、严重度与可能性。

  3. 定义功能

    安全动作、触发条件和所需性能。

  4. 设计实现

    机械、电气和安全控制措施。

  5. 验证确认

    证明功能满足要求。

  6. 管理变更

    定检、旁路、修改与再验证。

NON-NEGOTIABLE BOUNDARY

MES 不能成为安全功能前置条件

  • 不能靠 MES 在线才允许急停生效。
  • 不能通过普通 API 远程屏蔽安全门锁。
  • 不能把普通 HMI 的绿色图标当成安全验证。
  • 安全旁路必须受控、限时、可见且可审计。

SMART LOCK CASE

机器人单元开门

防护门打开后，安全系统停止危险运动并防止意外启动。MES 只接收“安全停机”事件用于工单影响分析，不能参与安全动作闭环或远程解除门锁。

JAVA BOUNDARY

应用层能做什么

  • 展示标明来源、更新时间和“非安全装置”。
  • 审计记录安全事件与生产影响，不改写源事实。
  • 维护流程支持审批和旁路登记，但不执行安全旁路。
  • 故障响应业务恢复计划服从机器安全状态。
