ISA-95：先分活动，再放系统

ISA-95 是企业与制造控制集成的坐标系。它定义活动、设备层级和交换信息，而不是要求每层购买一套固定产品。

OFFICIAL DEFINITION

官方解释与中文释义

ISA 官方将 ISA-95（亦称 IEC 62264）描述为企业系统与制造控制系统集成的国际标准系列，用层级模型组织技术和业务流程，并明确各层活动及接口。

白话：它像制造企业的城市规划和地址系统，先说哪类事情应在哪个边界完成，再说边界之间交换什么。

ACTIVITY LEVELS

L4—L0 不是五种软件

层活动智能锁例子
L4业务计划与物流订单、采购、主计划、成本
L3制造运营管理派工、过站、质量、维护、库存运营
L2监视、监督与自动控制PLC、机器人、线体监督控制
L1感知和操纵过程传感、扫码、阀、驱动与工具
L0实际物理过程装配、烧录、测试和包装

CORE MODELS

还要掌握三组模型

设备层级

企业 → 站点 → 区域 → 工作中心 → 工作单元。设备搬迁使用有效期，不能改写历史。

四类运营

生产、质量、维护、库存运营共同构成 L3，不等于只有“工单执行”。

交换对象

定义、能力、请求/计划、绩效/响应；L4 发目标，L3 返回事实。

SMART LOCK CASE

一条总装线如何落到设备层级

华东工厂是 Site，总装车间是 Area，智能锁 1 线是 Work Center，主板绑定、烧录、功能测试和包装是 Work Unit。每条测试结果都应带设备路径、会话和 SN，避免同名设备造成证据歧义。

IMPLEMENTATION

Java 设计重点

  • 稳定业务键层级对外用编码，不暴露数据库自增 ID。
  • 时间有效性换线、改造、能力变化以有效期表达。
  • 来源证据保存来源系统、外部 ID、版本和同步时间。
  • 双时间戳区分事件发生时间与平台接收时间。
