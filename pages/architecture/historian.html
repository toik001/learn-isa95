Historian：工业过程的时间黑匣子

Historian 高效保存带时间戳和质量码的过程值、状态与事件；MES 保存业务上下文、判定和原始证据定位。

典型层级：L2/L3主权：时间序列 / 过程证据来源等级：A

数据边界原始高频数据、文件和 MES 摘要的保存位置与期限必须按质量、法规、成本和查询需求确认。

OFFICIAL CONTEXT

过程历史与业务履历不同

NIST OT 架构描述了收集过程信息、支持趋势和后续运营分析的数据历史能力。

白话：Historian 保存“某个测点随时间怎样变化”，MES 保存“为什么对哪把锁做了这次测试、业务结论是什么”。

SAMPLE MODEL

数值之外还要保存什么

IDENTITY

tag_id

点位关联资产、通道和元数据版本。

TIME

双时间戳

source_timestamp 与 ingest_timestamp。

MEANING

单位和精度

不能让查询者猜测原始量纲。

TRUST

quality

Good、Uncertain、Bad 与具体原因。

RETENTION

压缩不能丢掉质量峰值

原始高频、分钟聚合、事件片段和质量关键数据采用不同保留策略。扭矩峰值、电流异常等不能被普通均值降采样掩盖。时钟同步和漂移监控是跨系统追溯成立的前提。

SMART LOCK CASE

从 SN 找回电机电流曲线

测试会话保存原始文件，Historian 保存关键时序，MES 保存 SN、程序、阈值版本、PASS/FAIL、峰值摘要、URI 和哈希。售后投诉时从 SN 反查当时会话及曲线。

IMPLEMENTATION

Java 实现重点

  • 分层存储不把百万采样点写入 MES 关系表。
  • 查询保护限制时间范围、点位数量和返回精度。
  • 证据完整URI、哈希、保留期和访问审计成套保存。
  • 会话关联资产、会话、SN 与时间窗共同定位。
