MES 学习驾驶舱/工业自动化体系/边缘网关

NODE 13 · LEVEL 1—LEVEL 3

边缘网关：翻译、缓冲与边界代理

网关接入异构设备、保留质量与顺序、断网存储转发，并把原始地址转换为标准资产语义；它不替 MES 做业务过站。

典型层级：L1—L3主权：接入 / 映射 / 缓冲来源等级：A/C

教学节点“边缘网关”不是 ISA-95 强制产品；其归层取决于实际活动。真实驱动、网络位置和离线策略待确认。

STANDARD BASIS

标准能力与白话

OPC UA 官方规范强调平台无关的信息模型、安全通信和互操作；NIST OT 指南强调现场协议与分区通信。

白话：网关不只是 TCP 转 JSON，它还要知道数据来自谁、单位是什么、是否可信、断网后按什么顺序补传。

CAPABILITIES

南向、北向和本地能力

南向

OPC UA、Modbus、串口、SDK、文件与旧设备协议。

北向

MQTT、OPC UA、HTTPS、gRPC 或消息总线。

本地

映射、质量码、序号、去重、缓存、水位和补传。

STATE

网关状态与设备状态分开

  • 未注册
  • 已配置
  • 已连接
  • 降级/离线
  • 补传中
  • 正常

网关在线不代表所有南向设备在线；设备影子只能表达最后已知状态，并显示数据新鲜度。

SMART LOCK CASE

旧扭矩枪串口接入

网关读取扭矩、角度、程序号和结果，补充设备、会话与时间质量后上送。网络中断时按序缓存，恢复后沿用原序号补传，MES 幂等接收。

IMPLEMENTATION

Java 实现重点

  • 驱动隔离单设备异常不拖垮整站。
  • 配置版本映射、证书、驱动可签名和回滚。
  • 水位保护磁盘将满时报警并执行明确降级策略。
  • 隔离队列未知单位、质量或版本不直接进业务链。
