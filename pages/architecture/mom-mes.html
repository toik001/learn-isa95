MOM / MES：制造运营的执行中枢

MOM 是生产、质量、维护和库存运营的整体管理体系；MES 是承载其中执行、采集、跟踪和分析能力的主要信息系统之一。

典型层级：L3主权：工序事实 / WIP / 谱系来源等级：A/B

产品边界MES 是否内置质量、仓储、维护或 APS 能力取决于企业架构；MOM 是能力范围，不等于必须由一个产品包办。

OFFICIAL EXPLANATION

MOM 与 MES 不完全同义

ISA 的 MOM/MES 说明将 MOM 概括为支持制造运营的过程、数据结构与通信整体，MES 是主要信息系统之一。

白话：MOM 是“车间运营应该怎样闭环”，MES 是常见数字化承载体。

FOUR OPERATIONS

L3 不只有生产工单

生产运营

排程、派工、执行、采集、跟踪和分析。

质量运营

检验、判定、隔离、处置和复验。

库存运营

现场请求、移动、消耗和在制跟踪。

维护运营

设备能力、保养、故障、维修和恢复。

STATE MACHINES

四条关键状态链

对象关键状态
工单创建→发布→下达→执行→完工→关闭
SN上线→在制→合格/冻结/返工→包装→入库→发货
工序待执行→已授权→执行中→未知/通过/失败→确认
设备会话创建→接受→运行→待确认→完成/失败/取消

SMART LOCK CASE

一次过站为什么由 MES 判定

MES 校验工单、路线、主板批次、固件兼容、操作者资格和设备校准，再创建测试会话。设备上传结果后，MES 结合版本与幂等规则形成过站，并绑定主板、指纹模组、固件和整锁 SN。

IMPLEMENTATION

Java 实现重点

  • 聚合边界围绕工单、SN、工序执行和设备会话建模。
  • 状态守卫数据库唯一约束和乐观锁共同防重复。
  • 未知态超时后查询原会话，不能自动创建第二次动作。
  • 审计证据记录人员、原因、前后值、来源和原始数据索引。
