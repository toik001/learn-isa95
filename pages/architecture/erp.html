NODE 03 · LEVEL 4

ERP：管理企业承诺与经营账

ERP 决定接什么单、采购什么、计划做多少，并核算库存和成本；MES 把这些经营目标转换为现场执行并回传实绩。

典型层级：L4主权：订单 / 经营库存 / 成本来源等级：B

边界ERP 产品实际模块和生产订单状态待确认；行业通用边界不代表企业一定由 ERP 管全部主数据。

OFFICIAL EXPLANATION

官方解释与白话

SAP将 ERP 描述为连接财务、人力、制造、供应链、销售和采购等核心业务流程的企业资源计划系统。

白话：ERP 管“企业答应了什么、需要准备什么、账上发生了什么”，不记录每个 PLC 测点。

DATA OWNERSHIP

ERP 证明什么

主数据

组织、客户、供应商、基础物料、单位和财务维度。

交易

销售、采购、生产订单以及库存和财务凭证。

MES 缓存

只保存生产所需快照和来源版本，不争夺经营主权。

不应承载

每把锁的高频曲线、PLC 报警和工位实时顺控。

INTERFACE

双向契约

方向对象控制点
ERP→MES生产订单、数量、交期、版本引用、优先级外部 ID、版本、取消与变更语义
MES→ERP开完工、合格/报废、消耗、入库请求幂等键、累计量、冲销与对账

SMART LOCK CASE

2,000 把 A100 的分工

ERP 生成需求并承诺交期；MES 冻结制造版本、拆工单并记录逐件执行。完工后回 ERP 的是 1,980 合格、15 报废、5 在制等实绩，而不是每把锁的扭矩曲线。

IMPLEMENTATION

Java 实现重点

  • Inbox/Outbox本地事务与外部消息可靠衔接。
  • 数量对账请求、确认、冲销和累计量都可核对。
  • 双状态区分 MES 已完成和 ERP 已确认。
  • 防重复唯一业务键阻止重复完工与重复扣料。
