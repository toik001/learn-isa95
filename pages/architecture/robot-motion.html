机器人与运动控制：精确地动

控制器管理坐标、轨迹、速度、工具、轴同步和动作程序；MES 管为什么为哪个工单和 SN 执行，不生成临时危险轨迹。

典型层级：L1/L2主权：轨迹 / 运动程序 / 循环来源等级：A

安全范围机器人本体安全与机器人应用集成安全不是一回事；围栏、协作、工具和工装须做应用级风险评估。

OFFICIAL STANDARD

ISO 10218 的范围

ISO 10218-1:2025规定工业机器人本体设计安全要求，其系列第二部分覆盖机器人应用集成。

白话：机器人“本身合格”不代表整套工作站已经安全，集成后的工具、夹具、人员进入和协同都要验证。

OBJECTS & STATES

程序发布与执行分开

工程对象

机器人/轴、工具中心点、工装、坐标系、程序、配方。

执行状态

空闲→已装载→运行→暂停→完成/故障。

程序状态应经历草稿、仿真、现场验证、批准、发布和退役。

MES INTERFACE

下发引用，不下发自由轨迹

MES 下发型号、SN、已发布程序/配方 ID；PLC 协调夹具与单元状态；控制器返回实际程序、循环号、结果和报警。控制完成仍需质量测量才能形成产品合格。

SMART LOCK CASE

面板抓取与压合

机器人把前面板放入夹具，伺服压合结构件。MES 选择批准配方，机器人决定轨迹，PLC 协调到位与安全；实际程序和循环号关联整锁 SN。

IMPLEMENTATION

Java 实现重点

  • 权限分离配方选择、程序发布和维护修改分别授权。
  • 版本回传保存实际执行版本，不只保存期望版本。
  • 质量分离动作完成与测量合格是两个事实。
  • 影响分析错误程序按循环号、时间窗和 SN 追溯。
