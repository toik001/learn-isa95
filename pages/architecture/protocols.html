NODE 19 · CROSS-LAYER COMMUNICATION

工业协议：能传，不等于能懂

实时控制、结构化互操作、异步遥测、旧设备寄存器和业务事务需要不同协议；任何协议都必须补齐资产语义、质量、顺序、安全和版本。

范围：跨层核心：传输 + 语义 + 可靠性来源等级：A

选型原则协议没有绝对高低之分。先明确实时性、拓扑、设备能力、语义、安全与运维条件，再选技术。

OFFICIAL EXPLANATIONS

四类能力

OPC UA

平台无关的信息模型、安全通信和互操作。

MQTT

轻量发布/订阅，适合异步遥测；主题不自动产生制造语义。

Modbus

通过功能码访问线圈和寄存器，地址语义需另行约定。

实时工业以太网

面向控制循环、分布式 I/O 和多轴运动的确定性通信。

SELECTION

按需求选择

需求常用能力重点
控制循环工业实时以太网/现场总线确定性、诊断、拓扑
结构化互操作OPC UA建模、证书、订阅
异步遥测MQTT主题、QoS、会话、积压
旧设备接入Modbus/串口地址、字节序、缩放、轮询
业务系统HTTPS/gRPC/消息幂等、版本、事务、审计

INFORMATION CONTRACT

跨层事件最低字段

event_id、schema_version、source、equipment_id、session_id、sequence、occurred_at、received_at、quality、payload、trace_id。

另需定义单位、精度、状态码、重复、乱序、补传、超时、身份、授权和版本退役。

SMART LOCK CASE

三种协议共存

旧扭矩枪用 Modbus，网关标准化后 MQTT 上送；新测试台提供 OPC UA 信息模型；MES 用 HTTPS 创建业务会话。它们通过统一设备、会话和 SN 串起来。

IMPLEMENTATION

Java 易踩坑

  • QoS 非幂等至少一次投递仍可能重复执行。
  • 质量非数值OPC UA Bad 不能转成默认 0。
  • 寄存器编码处理字节序、字序、无符号和快照一致。
  • 模式演进消费者与生产者支持兼容窗口。
