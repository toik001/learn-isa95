QMS：把质量问题闭环到放行

质量管理体系覆盖标准、检验、问题、根因、处置、纠正预防和持续改进；测试 FAIL 只是闭环的起点。

OFFICIAL EXPLANATION

官方解释与白话

ISO将 QMS 解释为组织为满足客户和法规要求、持续改进质量而建立的过程和程序体系。

白话：QMS 不是一张检验结果表，而是从标准到问题、从隔离到放行的完整管理闭环。

QUALITY OBJECTS

规则、结果、处置分开

规则

检验规范、抽样、限值版本、缺陷代码。

结果

特性值、单位、判定、仪器、操作者、原始证据。

处置

返工、报废、让步、退货、复验与放行。

CLOSED LOOP

NCR 与 CAPA 状态

NCR：发现→登记→隔离→评审→处置→复验→关闭。CAPA：问题定义→根因→措施→实施→效果验证→关闭。`PASS/FAIL` 不能表达让步接收，也不能替代批准放行。

SMART LOCK CASE

电机电流连续偏高

MES 保存失败 SN、批次和曲线索引并触发冻结；QMS 以主板/电机批次扩展影响范围，评审后发布返工处置。返工走批准路线，复验通过后再解除冻结。

IMPLEMENTATION

Java 实现重点

  • 版本判定历史结果按当时限值解释。
  • 跨系统冻结MES、WMS、ERP 状态需补偿和对账。
  • 影响范围用谱系图按批次、时间窗、设备程序扩展。
  • 批准审计让步、报废、放行都记录权限与原因。
